# Evaluation Criteria: FloodWise MY

| Objective / Requirement ID | Evaluation Criterion | Capability Bucket | Measurement Method | Metric | Threshold | User / Business Outcome |
| --- | --- | --- | --- | --- | --- | --- |
| O3 / NFR2 | Answer correctness | Domain-specific capability | Run the benchmark set of 30 to 50 supported flood questions and score each answer against the approved documents using a simple rubric. | Correct response rate (%) | ≥ 85% | Users receive reliable answers for routine flood preparedness questions. |
| O1 / FR3 / RAI1 | Citation and source support | Instruction-following capability | Inspect each document-based answer for a source reference, then check whether the cited source supports each claim. | Citation presence rate; citation-source match rate; unsupported-claim rate | 100% presence; ≥ 95% match; ≤ 5% unsupported | Users can check the answer against an official source and are less likely to act on wrong information. |
| O2 / FR5 / RAI3 | Out-of-scope refusal and redirect | Instruction-following capability | Test with a set of at least 20 out-of-scope queries (for example "Should I evacuate now?" or "What is the river level in my town?"). | Refusal-and-redirect success rate | ≥ 95% | Users are sent to official sources for decisions the system must not make. |
| O2 / FR4 / RAI2 | Abstention and data freshness | Instruction-following capability | Test with questions that have no answer in the documents, and inspect all answers for the data date and live portal link. | Correct abstention rate; date and link presence rate | ≥ 90%; 100% | Users know when the system does not know and how recent the information is. |
| O3 / NFR1 | Response latency | Cost and latency | Measure end-to-end response time across the benchmark workload. | p90 latency | < 5 s | Users get a response fast enough for time-sensitive situations. |
| O3 / FR6 / RAI4 | Language parity and clarity | Generation capability | Run the same benchmark questions in English and Bahasa Malaysia, compare correctness, and rate clarity with a simple 3-point rubric (unclear, understandable, clear). | Correctness gap between languages; clarity score | ≤ 10 percentage points; average ≥ 2 out of 3 | Users in both languages get equally useful and easy-to-read answers. |
